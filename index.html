合并规则
打卡记录取并集（两边打过的勾都不会丢）、科目进度取较大值、连续打卡取较大值、 目标分和词量以当前设备为准。所以两台轮流用不会互相覆盖。

⚠️ 最重要的一条
千万不要在第二台上点「新建空间」—— 那会建出一个新的空空间，两台就永远对不上了。 这正是你之前「同步失败」的原因。
怎么拿 Token（3 分钟）
① GitHub → 右上角头像 → Settings
② 左侧拉到最底 → Developer settings
③ Personal access tokens → Tokens (classic) → Generate new token (classic)
④ Note 填 zhimiao-sync，Expiration 选 No expiration
⑤ 权限只勾一个 gist，其它全部不要勾
⑥ 点最下面 Generate token，复制那串 ghp_ 开头的字符
它只显示这一次，先存到备忘录。

Token 会消失是怎么回事
iOS 把主屏图标删掉重加时，会清空这个 App 的本地存储，Token 和最终同步空间 ID 都会没。 所以：图标更新时别删旧的，或者把 Token 和空间 ID 抄在备忘录里，随时填回来。

怎么放到 iPhone 上 GitHub Pages

放上去之后，你的链接是：
https://你的GitHub用户名.github.io/zsb-plan/
在 iPhone Safari 打开这个链接 → 分享 → 添加到主屏幕，就变成一个全屏 App 图标。
方式一：网页上传（推荐，手机就能做完）
① 注册 GitHub
手机浏览器打开 github.com → Sign up，用邮箱注册（免费）。

② 新建仓库
登录后点右上角 + → New repository
Repository name 填 zsb-plan（必须一致，否则链接要改）
选 Public → 点 Create repository

③ 上传文件
仓库页面点 Add file → Upload files → 一次把这 3 个文件全选上： E:\专升本学习计划\index.html
E:\专升本学习计划\icon-180.png
E:\专升本学习计划\icon-512.png 拉到底点 Commit changes
三个一起传。只传 index.html 也能用，但主屏幕图标会变成网页截图。

④ 开启 Pages
仓库页面点 Settings → 左侧找 Pages
Source 选 Deploy from a branch
Branch 选 main，目录选 / (root) → 点 Save

⑤ 等 1-2 分钟
回到 Pages 页面，顶部会出现你的网址，点开就能用了。

⑥ 加到主屏幕
iPhone 用 Safari 打开网址 → 底部 分享 → 添加到主屏幕
方式二：电脑命令行（更快，一步到位）
这个文件夹里我已经建好 git 仓库并提交了，你只要：

① 在 GitHub 上新建一个名为 zsb-plan 的仓库（不要勾选任何初始化文件）

② 在 E:\专升本学习计划 目录下打开终端，执行：
git remote add origin https://github.com/你的用户名/zsb-plan.git
git push -u origin main ③ 弹出登录时，密码要填 Personal Access Token（不是账号密码）：
GitHub → 头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 勾选 repo → 生成后复制

④ 推送完成后，去仓库 Settings → Pages 开启（同方式一第④步）
方式三：先打印成纸质版贴墙
在电脑浏览器里按 Ctrl+P / Cmd+P，选「另存为 PDF」或直接打印。 纸质的用来贴墙看阶段目标，手机上的用来每天打卡。
以后要改内容怎么办？
改完电脑上的 index.html 后：
· 方式一上传的 → 在 GitHub 仓库里点进 index.html → 铅笔图标 → 直接改 → Commit
· 方式二上传的 → 在文件夹里执行 git add . → git commit -m "更新" → git push

换了图标也要重新传
图标是 icon-180.png 和 icon-512.png 两个文件。 换图标后重新上传这两个文件，然后在 iPhone 上把主屏幕那个图标删掉重新添加一次，才会更新。

注意：网页上的打卡数据存在手机本地，更新代码不会丢失数据。
但换手机或清缓存会丢，所以定期用上面的「导出备份」存一份到备忘录。
